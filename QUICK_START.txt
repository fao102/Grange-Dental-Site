## Deploy to Netlify (Easiest - FREE)

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Grange Dental Surgery website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/grange-dental-surgery
git push -u origin main
```

### Step 2: Deploy to Netlify
1. Go to **https://netlify.com**
2. Click **Sign up** (free)
3. Click **New site from Git**
4. Connect your **GitHub account**
5. Select your `grange-dental-surgery` repo
6. Settings auto-fill correctly
7. Click **Deploy**

### ✅ Done! Your Site is Live
You'll get a URL like: `https://[random-name].netlify.app`

---

## Alternative: Deploy to Vercel (Equally Easy)

1. Go to **https://vercel.com**
2. Click **Sign up** (free)
3. Click **Import Project**
4. Select your GitHub repo
5. Click **Deploy**

**Result:** Live in 2 minutes with auto-updates!

---

## OR: Manual Upload (for existing web host)

1. Upload contents of `build/` folder to your server's `public_html` or `www` folder
2. Done!
